# todone themes

Plug-and-play color palettes, ported from [`avredit`](../../avredit)'s
theme collection and converted to todone's colors-only `theme.json` schema
(see `docs/PLAN.md` → Theming). These files aren't read from here directly —
copy the one you want to the config path:

```sh
cp themes/tokyo-night.json ~/.config/todone/theme.json
```

Mix-and-match is also fine: copy a file, then hand-edit individual fields —
any field you remove or leave out just falls back to todone's built-in
default.

- `dracula.json`
- `gruvbox.json`
- `light.json`
- `minimal-dark.json`
- `monokai.json`
- `one-dark-pro.json`
- `rose-pine.json`
